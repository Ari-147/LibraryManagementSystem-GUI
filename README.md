# LibraryManagementSystem-GUI
This is a Small project in OOP Java that makes a basic Library System that shows Books Members also has a Search Feature

📋 Features
📚 Library Management System
A Java-based Library Management System with a graphical user interface (GUI) using Swing.

Book Management:

Add books with details like ID, Title, Author, and Publisher.
View all books in the library.
Issue and return books with automatic updates to availability and timestamps.
Member Management:

Add members with unique IDs and names.
Search members by ID or name.
Search Functionality:

Search books by ID, title, author, or publisher.
Search members by ID or name.
Data Persistence:

Save book and member data to local .notes files.
Load previously saved data from files.
Graphical User Interface (GUI):

Easy-to-use GUI designed with Java Swing.
Buttons for each core functionality.
Real-Time Notifications:

Alerts for success or errors (e.g., book issuance, invalid input).
